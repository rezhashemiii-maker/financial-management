# جزوهٔ مدیریت مالی — کنکور کارشناسی ارشد

یک سایت استاتیک ساده که به‌عنوان **جزوهٔ شخصی مدیریت مالی** استفاده می‌شود: یک صفحهٔ اصلی و برای هر جلسهٔ کلاس یک بخش (صفحهٔ) مستقل.

## ساختار

```
.
├── index.html              صفحهٔ اصلی — فهرست جلسه‌ها
├── assets/
│   ├── styles.css          استایل مشترک (RTL، حالت روشن/تاریک، استایل پرینت)
│   └── app.js              تم، هایلایت فهرست، دکمهٔ بالا، باز کردن همهٔ پاسخ‌ها
└── sessions/
    └── 01-koliyat.html     جلسهٔ ۱ — کلیات مدیریت مالی (فصل اول)
```

## محتوای جلسهٔ ۱ (فصل اول: کلیات)

1. تعریف و قلمرو مدیریت مالی (منابع و مصارف سرمایه)
2. هدف مدیریت مالی و دلیل رد «حداکثرسازی سود»
3. ارزش ذاتی سهم و مدل گوردون
4. بازده سهم (سود نقدی + سود سرمایه‌ای)
5. ریسک و رابطهٔ مستقیم ریسک–بازده
6. اشکال سازمان‌های تجاری (انفرادی، تضامنی، سهامی) + جدول مقایسه
7. مسئله و هزینه‌های نمایندگی + ۴ سازوکار ایجاد انگیزه
8. دارایی مشهود و نامشهود
9. طبقه‌بندی بازارهای مالی بر اساس ۵ معیار (تا بازار چهارم)
10. مؤسسات تأمین سرمایه
11. بازار کارا: ویژگی‌ها، انواع کارایی، سطوح کارایی اطلاعاتی
12. صندوق‌های سرمایه‌گذاری و محاسبهٔ NAV
13. ۱۸ تست با پاسخ تشریحی (شامل تست‌های کنکور ۹۴، ۹۸ و دکتری مالی ۱۴۰۲)
14. فرمول‌نامه و چک‌لیست مرور

## اجرا

نیازی به build نیست — فایل `index.html` را در مرورگر باز کن. یا:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## اضافه کردن جلسهٔ جدید

1. از `sessions/01-koliyat.html` یک کپی بگیر (`sessions/02-....html`) و محتوا را عوض کن.
2. در `index.html` کارت آن جلسه را از حالت `card soon` به کارت فعال با لینک تغییر بده.
